# Evidence Index

## Interpretation and Provenance

Evidence distinguishes:

- **Live-lab:** Events generated by actual local API operations.
- **Synthetic:** Deliberately constructed fixture events.
- **Replay:** Explicitly labeled historical fixtures.
- **Automated tests:** Isolated checks using controlled data and injected dependencies.

Ground truth describes the authorized laboratory scenario. It is not supplied
to detection rules as an intent label.
